# Icon concept

`Icon.svg` is the editable draft: a single contact card divided into three facets, representing Work, Personal, and Combined. No QR-reader motif. The outer background remains square; Apple applies the platform's mask.

This is a vector concept, not yet an AppIcon asset catalog or a final store icon. Before release, review at small iPhone and circular Watch sizes, create the required raster/icon-composer assets, and validate the archived asset catalog.
